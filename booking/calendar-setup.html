Victoria Tuition Academy — Live Calendar Setup

This one-time setup creates two Google Calendars and connects live availability to the booking page.

  1. Open script.google.com in the Google account you use for your calendar.
  2. Create a New project.
  3. Delete the sample code, then tap Copy setup code below and paste it into the project.
  4. Choose initialSetup at the top and press Run. Approve Google Calendar access. This creates Victoria Tuition Academy — Work and Victoria — Personal and moves genuine confirmed lessons into Work.
  5. Press Deploy → New deployment → Web app. Set Execute as: Me and Who has access: Anyone, then deploy.
  6. Copy the URL ending in /exec and send it back to ChatGPT. I’ll attach it permanently to the booking site.
The calendar event names stay private. Students receive only Available / Unavailable time slots.
