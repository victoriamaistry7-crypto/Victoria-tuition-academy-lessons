TERM 1

Number skills first

Strong algebra depends on strong number sense.

Integers: signs matter

Integers include positive numbers, negative numbers and zero.

−7 + 12 − 5 = 0
1
Start at −7.
2
Add 12 → move 12 steps right → 5.
3
Subtract 5 → move 5 steps left → 0.

Quick check: Calculate −9 + 14 − 3.

2 marks
−9 + 14 = 5, then 5 − 3 = 2.
Term 1 • Exponents

Exponent laws you must know

aᵐ × aⁿ = aᵐ⁺ⁿ
aᵐ ÷ aⁿ = aᵐ⁻ⁿ
(aᵐ)ⁿ = aᵐⁿ
Common mistake: do not multiply exponents when multiplying the same base. You add them.

Worked example

3² × 3⁴ ÷ 3³

1
Same base → add exponents when multiplying: 3²⁺⁴ = 3⁶
2
Divide same base → subtract exponents: 3⁶⁻³ = 3³
3
3³ = 27

Simplify: 2⁵ × 2² ÷ 2³

2 marks
5 + 2 − 3 = 4, therefore 2⁴ = 16.
Term 1 • Algebraic expressions

Like terms and distributive law

1. Collect like terms

3x + 5x − 2 = 8x − 2

Only terms with exactly the same variable part can be combined.

2. Remove brackets

3(x + 4) = 3x + 12

Exam habit

When simplifying, work in this order:

1
Remove brackets.
2
Collect like terms.
3
Write the final expression neatly.

Simplify: 2(3x − 4) + x

3 marks
2(3x − 4) = 6x − 8, then +x gives 7x − 8.
Term 1 • Patterns & functions

From a pattern to a rule

For a linear number pattern, identify the constant difference first.

5, 9, 13, 17, ...

Difference = +4.

A possible nth-term rule is:

Tₙ = 4n + 1
Check: when n = 1, T₁ = 4(1)+1 = 5 ✓

Function machine

y = 3x − 2

For y = 3x − 2, find y when x = 5.

2 marks
y = 3(5) − 2 = 15 − 2 = 13.
TERM 2

Equations and graphs

This is where algebra starts becoming more visual.

Solving linear equations

3x + 5 = 20
1
Subtract 5 from both sides → 3x = 15
2
Divide both sides by 3 → x = 5
Balance rule: whatever you do to one side of the equation, do to the other side.

Check your answer

Substitute x = 5 into the original equation:

3(5) + 5 = 20

20 = 20 ✓

Solve: 4x − 7 = 13

3 marks
4x − 7 = 13 → 4x = 20 → x = 5.
Term 2 • Linear graphs

Gradient tells us how steep a line is

m = (y₂ − y₁) / (x₂ − x₁)

Using (1,2) and (3,6)

m = (6 − 2)/(3 − 1)

m = 4/2 = 2

Positive gradient → line rises from left to right. Negative gradient → line falls.

Find the gradient between (2, 1) and (6, 9).

3 marks
m = (9−1)/(6−2) = 8/4 = 2.
Term 2 • Straight-line geometry

Parallel lines + a transversal

Corresponding angles: equal.
Alternate angles: equal.
Co-interior angles: add to 180°.
Always write the reason in geometry questions. Marks are often awarded for both the answer and the reason.

If the marked angles are corresponding, find x.

2 marks
Corresponding angles on parallel lines are equal, so x = 68°.
Mid-lesson checkpoint

Can you connect the skills?

This is a short mixed question. Read it carefully before calculating.

The rule is y = 2x + 1. Which point lies on the graph?

3 marks
Substitute x = 3: y = 2(3) + 1 = 7, so (3,7) lies on the graph.
Exam strategy: if a question gives a rule and a coordinate, substitute the x-value and check whether the calculated y matches the point.
TERM 3

Geometry and measurement

Draw, label, use the correct formula, and always include units.

Exterior angle theorem

The exterior angle of a triangle equals the sum of the two opposite interior angles.

120° = 50° + x
x = 70°

An exterior angle is 135°. One opposite interior angle is 55°. Find the other.

3 marks
135° = 55° + x, so x = 80°.
Term 3 • Area & perimeter

Know what the question is asking

Perimeter

Distance around the outside of a shape.

P = 2ℓ + 2w

Area

Space inside a 2D shape.

A = ℓ × w

A rectangle is 8 cm by 5 cm. What is its perimeter?

2 marks
P = 2(8) + 2(5) = 16 + 10 = 26 cm.
Term 3 • Circles

Radius, diameter and area

A = πr²

Worked example

A = (22/7)(7²)

A = (22/7)(49)

A = 154 cm²

Area uses square units: cm², m², mm².

Using π = 22/7, find the area of a circle with radius 14 cm.

3 marks
A = (22/7)(14²) = (22/7)(196) = 616 cm².
Term 3 • Data handling

Mean, median, mode and range

MeasureMeaningHow to find it
MeanAverageAdd all values ÷ number of values
MedianMiddle valueOrder the data first
ModeMost frequentFind the value that appears most
RangeSpreadLargest − smallest

Data set: 4, 6, 6, 8, 11

Mean = (4 + 6 + 6 + 8 + 11) ÷ 5 = 7

Median = 6 • Mode = 6 • Range = 11 − 4 = 7

For 3, 5, 5, 8, 9, what is the range?

2 marks
Range = largest − smallest = 9 − 3 = 6.
Term 3 • Probability

Compound probability

When two fair coins are tossed, list the equally likely outcomes systematically.

Probability of exactly one head

Favourable outcomes: HT, TH

Total outcomes: 4

P(exactly one H) = 2/4 = 1/2

What is the probability of getting two tails?

2 marks
Only TT gives two tails. That is 1 favourable outcome out of 4 → 1/4.
Final challenge

Mixed exam-style mastery check

These questions combine skills from the three terms. Work carefully and use the method you have revised.

1. Simplify: 5x − 2(x − 3)

3
5x − 2x + 6 = 3x + 6.

2. If y = −2x + 5, find y when x = 3.

2
y = −2(3)+5 = −6+5 = −1.

3. A triangle has angles 48°, 67° and x. Find x.

2
Angles in a triangle add to 180°. x = 180 − 48 − 67 = 65°.

4. Mean of 6, 7, 8, 9, 10?

2
Total = 40, and 40 ÷ 5 = 8.
