QUESTION 1.1
Which statement best describes electric current in a complete circuit?
[2]
Teacher correction

Current is the rate of flow of electric charge. It is measured in amperes (A).

Exam memory: current → charge flow → ammeter → amperes.
QUESTION 1.2
A voltmeter must be connected …
[2]
Teacher correction

A voltmeter compares the electrical potential at two points, so it must be connected across the component.

Memory trick: A in series, V across.
QUESTION 2.1
Three resistors of 4 Ω, 3 Ω and 5 Ω are connected in series. Calculate the total resistance.
[4]
Teacher correction

In a series circuit, all resistors lie on one path, so the total resistance is the sum.

Rtotal = 4 + 3 + 5 = 12 Ω.
QUESTION 2.2
An ammeter reads 0.40 A before the first resistor in a series circuit. What current should it read after the second resistor?
[3]
Teacher correction

A series circuit has only one path, so the same current flows through every point in that path.

QUESTION 2.3
Two identical lamps are connected in parallel. One lamp is removed, opening only its branch. What happens to the other lamp?
[3]
Teacher correction

Parallel branches are separate paths. Opening one branch does not automatically open the others.

Exam wording: the other lamp remains connected across the source on its own complete branch.
QUESTION 3.1
A learner investigates how the length of a nichrome wire affects current. What is the independent variable?
[3]
Teacher correction

The independent variable is the factor deliberately changed by the learner.

IV = changed. DV = measured. Controls = kept the same.
QUESTION 3.2
Why must the thickness of the wire be kept constant in the investigation?
[3]
Teacher correction

Thickness affects resistance. A fair test changes one relevant factor at a time.

QUESTION 4
Study the circuit diagram below. Which description is correct?
[5]
Teacher correction

Trace the paths first: there are two lamp branches, so the lamps are in parallel. The ammeter is in the main path, while the voltmeter bridges the lamp.

Diagram strategy: count paths → find A in series → check if V spans the component.
QUESTION 5.1
Two extra resistors are added in series to a working circuit. What happens to the total resistance?
[3]
Teacher correction

Each resistor in series adds more opposition to the same path, so total resistance increases.

QUESTION 5.2
At a junction in a parallel circuit, what happens to the total current?
[3]
Teacher correction

At a junction, charge can take more than one path, so the current splits between those branches and recombines later.
