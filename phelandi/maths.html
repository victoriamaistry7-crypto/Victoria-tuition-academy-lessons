02 • Retrieval

Clean algebra first.

Straight-line graphs depend on algebra. Start by combining only like terms.

7x − 3 + 2x + 5 = 9x + 2

Variable terms

7x + 2x = 9x

Constants

−3 + 5 = 2

Simplify: 4a + 7 − a + 3
03 • Equations

Keep the balance.

Instead of “moving” numbers magically, perform the same operation on both sides.

4x − 7 = 21
1
Add 7 to both sides → 4x = 28
2
Divide both sides by 4 → x = 7
3
Check: 4(7) − 7 = 21 ✓
Solve: 5x + 4 = 34
04 • Brackets

Two valid routes. Same answer.

3(x − 2) = 15

Route A

Divide by 3 → x − 2 = 5 → x = 7.

Route B

Expand → 3x − 6 = 15 → 3x = 21 → x = 7.

Solve: 2(x + 4) = 18
05 • Coordinates

A point has an address.

Coordinates are written (x ; y): move horizontally using x, then vertically using y.

x-coordinate

Left/right movement.

y-coordinate

Down/up movement.

Which point means “3 units right and 2 units down”?
06 • Straight-line equation

Meet y = mx + c.

y = mx + c

m = gradient

How much y changes when x increases by 1.

c = y-intercept

The y-value where the line crosses the y-axis.

For y = −3x + 4, identify m and c.
07 • Table to graph

Substitute, plot, connect.

For y = 2x − 1, substitute each x-value to calculate y. Every pair becomes a coordinate.

08 • Gradient

Gradient measures steepness and direction.

m = Δy / Δx

m > 0

Line rises left to right.

m < 0

Line falls left to right.

m = 0

Horizontal line.

A line passes through (1 ; 2) and (3 ; 8). What is its gradient?
09 • Interpret

Read the equation like a story.

For y = −2x + 6: the negative gradient means the line falls left-to-right, and c = 6 means it crosses the y-axis at 6.

Which description matches y = −2x + 6?
A line has gradient 3 and y-intercept −2. Which equation is correct?
